# MARQA LAB 17 — Essência
Proposta editorial em avaliação: "O que se vê é só o começo."

Este laboratório é derivado do LAB 16, com loader da logomarca original, hero e JavaScript de autoplay preservados. O módulo "Essência" foi adicionado diretamente após o hero. Controles técnicos foram movidos para um painel recolhido ao final e a ordem dos módulos provisórios foi ajustada para Hero → Essência → Expertise → Projetos → Contato.

Arquivos: index.html, sections/essencia.css, sections/essencia.js. Mídia necessária para reprodução completa: assets/marqa-hero-1080p.mp4 e assets/marqa-hero-poster.jpg, copiados do pacote LAB 16; símbolo original: assets/marqa-symbol-white.png (também versionado no LAB 16). Os binários não são duplicados neste laboratório no GitHub. **Use o ZIP completo entregue na conversa para testar e publicar no Netlify.**

O vídeo original em 4K está preservado no Drive. Os módulos Expertise, Projetos e Contato continuam provisórios e sem conteúdo final aprovado. O LAB 17 não altera a aplicação React/Vite de produção até a integração aprovada.
