# LAB 08 — MARQA Hero com vídeo corrigido

Vídeo do usuário reprocessado em MP4 H.264 sem áudio, 960×540, 30fps, 7,9 segundos e faststart. O `<video>` utiliza `<source src="assets/hero-marqa.mp4" type="video/mp4">` com arquivos externos em vez de Blob JavaScript. Poster JPEG servido separadamente. O player tem autoplay muted playsinline loop, play/pause manual visível e overlay legível. A abertura LAB 04 aprovada e o Header LAB 05 original não foram editados; este arquivo é apenas prévia do Hero, não integração ao app principal.

Avaliar em navegador HTTPS; preview de arquivo cru no GitHub exibe código, não executa HTML.
