Versão experimental a partir do LAB 18.4. Hero, vídeo e loader não modificados.

**Seção 02 (Essência):** novo registro real de bastidores, extraído de um vídeo de 19,7s originalmente fornecido pelo usuário. O texto anterior e o layout base foram preservados.

**Seção 04 (Selected Work):** Le Vive, Vanllu e Espaçolaser Canaã. Imagens de Le Vive e marca Vanllu vieram de arquivos reais disponíveis no Drive; miniatura de câmera veio do vídeo fornecido pelo usuário. Os links abrem os filmes originais armazenados no Drive. Não atribuir a gravação de bastidores a um cliente específico.
