# PORTFÓLIO MARQA

Link na bio e portfólio institucional da MARQA.

Projeto em construção, com componentes independentes, dados separados e direção criativa definida por etapas. O arquivo V7 anterior será usado apenas como referência visual e editorial, não como código-base monolítico.

## Executar

```bash
npm install
npm run dev
```

## Estrutura

- `src/components/`: seções visuais independentes
- `src/data/`: conteúdo e configurações
- `src/styles/`: tokens, estilos globais e layouts
- `public/media/`: fotos, capas e vídeos aprovados

## Processo

1. Estrutura técnica
2. Curadoria do conteúdo e dos ativos reais
3. Direção de arte e prototipagem de cada componente
4. Testes de desempenho, responsividade e acessibilidade
5. Publicação no Netlify e controle de versões

Sem métricas inventadas, sem vídeos automáticos pesados e sem promessas de resultado.
