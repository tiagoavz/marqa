# MARQA × Dr. Denny — Estudo Diagnóstico V1

Estudo consultivo produzido a partir da reunião de 31/10/2026 (transcrição compartilhada com a MARQA). Cópia de acesso externo para evitar problemas com os links de download do chat.

## Arquivos

- [index.html](index.html): **versão para o cliente**, sem painel de edição
- [modelo-editavel.html](modelo-editavel.html): **versão interna editável**, com editor e exportação de HTML

## Publicar um teste no Netlify

1. No GitHub, abra `index.html` e clique em **Raw / Download raw file**.
2. Salve o conteúdo como `index.html` dentro de uma pasta no computador.
3. Entre em https://app.netlify.com/drop e arraste a pasta para a publicação manual.

Como alternativa, utilize **Add new project > Import an existing project**, conecte a este repositório e escolha a branch `preview/dr-denny-diagnostico-v1`. Configure base directory `estudos/dr-denny-v1`, publish directory `.`, sem comando de build.

## Notas de uso

- O conteúdo inclui hipóteses estratégicas, não promessas de resultado.
- Os valores de ticket médio são cenários para discussão, não preços confirmados do Dr. Denny.
- Confirme CRM, RQE quando aplicável, técnica, autorização de uso de imagens e demais informações médicas antes de enviar.
- Essa branch não muda o site institucional nem substitui o modelo-mestre.
