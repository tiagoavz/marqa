# Biblioteca de mídia

Inserir somente imagens e vídeos autorizados, otimizados para web.

Regras:
- Capas locais em AVIF/WebP quando possível.
- Vídeos reais preferencialmente por CDN/hospedagem de vídeo; não commitar arquivos grandes.
- Cada projeto deve ter legenda, texto alternativo e informação de créditos.
- Evitar autoplay com som e prever alternativa para conexão lenta.
